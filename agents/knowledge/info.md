# I. Conceptual Separation

## 1️⃣ Policy Database = “Should Layer” (Normative)

**Encodes:**
- Hard constraints  
- Risk tolerances  
- Corporate strategy  
- Governance rules  
- Escalation logic  

**It defines:**
> What is allowed, forbidden, preferred, or escalated.

**This prevents:**
- Rogue LLM creativity  
- Over-optimization  
- Unbounded action  


---

## 2️⃣ Shared Knowledge Database = “Is Layer” (Descriptive Memory)

**Encodes:**
- Market priors  
- Historical performance  
- Volatility regimes  
- Learned heuristics  
- Post-mortem learnings  
- Stakeholder explanations  

**It defines:**
> What the system knows about the world and itself.
